# Camera, directory and movement polish

The latest supplied still (`17660.jpg`) is the framing reference for this pass.
It supersedes the earlier panorama's tree-left composition. This is a staged
reconstruction of that composition, not a claim of an exact photogrammetric match.

The exterior sensor sits on the centreline of the sunken stair opening, on its
closed roof. Holston emerges away from it, goes around the side of the opening,
approaches the lens, cleans it, then climbs to Allison on the right-hand slope.
The hatch leaves and tunnel roof lie flat. Camera framing includes the stair lip,
the full cleaner, the tree crown and Allison. The circular earthwork still hides
neighbouring hatches; the flat exterior plain and numbered network are preserved.

The feed has less blur before cleaning and a cooler, subdued tone. Added scree is
batched with the existing rocks. The reduced tree and cross-slope resting pose
make the body easier to distinguish. Only the exterior feed uses daylight.

The directory now identifies the current level, supports padded level numbers,
shows a search count and clear action, and offers a shortcut to the current story
lead. Wings expand within each entry. Locked special destinations explain why.
Tabs support keyboard navigation. Screen focus and skip controls remain visible
during the opening. Compact screens get a scrollable start menu.

Resident capsules turn toward a new route before accelerating, retain their
individual walking speeds, and update smoothly nearby. Arm swing, shoulder twist
and pelvis sway are reduced for all shared rigs. Fast turns release foot anchors;
Holston also blends his heading changes.

Validation includes collision-driven walks through the exit and to the sensor,
the full opening and cloth contact, camera projection bounds, crater occlusion,
resident turning and the complete repository test suite. Desktop and phone-width
directory layouts, numeric search, clear and story-lead filtering were exercised
in an isolated browser UI fixture using the actual directory code and stylesheet.
An offline software render of the actual scene geometry checked composition.
The cloud browser could not create WebGL, so full live rendering, final material
appearance and a real-time visual playthrough remain unverified in this environment.

Integrated on top of the latest Claude changes to the silo clock, ambient audio,
night lighting and debug handles. Those systems and the reverted grading pass
are preserved.
